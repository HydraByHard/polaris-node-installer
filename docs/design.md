# Polaris Node Installer — решение

ТЗ владельца от 17.11.2026: автономная установка на новой Ubuntu, без изменения production при разработке. Новый отдельный Config Profile, собственный Inbound, Node и Host. Host изначально disabled AND hidden, профиль не назначен действующим Squads. Последующая публикация требует отдельного явного подтверждения владельца.

Bash — проверяемый автономный артефакт с встроенным Python zipapp. Python stdlib, официальные Docker Engine/Compose, закреплённые образы Node, Nginx и Certbot. HTTPS/h2/XHTTP packet-up, TLS завершается на новой VPS, Xray слушает loopback. Node API: native mTLS/SNI + allowlist исходящих IP Panel в отдельных INPUT chains IPv4/IPv6. Никаких flush/default-policy/SSH/Tailscale изменений. Containers host-network, чтобы INPUT-защиту не обходил DNAT Docker.

Сопряжение: API3.4.11 имеет scopes, но не одноразовую регистрацию нод. OTT служебный, токен минимум1день, его удаление требует adminJWT. Простой безопасный вариант: владелец одним действием в Panel создаёт отдельный1-дневный токен с10точными read/create scopes. Он вводится скрыто, используется толькоRAM; нет adminпароля/сохранённогоAPI-токена на VPS. Installer не может PATCH/DELETE через enrollment-клиент. Нельзя называть этот нативный токен криптографически одноразовым: до истечения он повторно применим; рекомендуется удалить сразу после установки. Публикация — отдельный токен с узкими read/update scopes, подтверждение PUBLISH, добавление только новогоInbound в Polaris personal с сохранением старого списка. Нативного CAS нет: требуется отсутствие параллельного редактирования этогоSquad; двойное чтение ловит наблюдаемую гонку.

Идемпотентность: root-only atomic state + lock; стабильные маркеры ресурсов; намерение сохраняется перед сетевой операцией, read-before-create reconciles after ambiguous response. Native node cert генерируется GET/keygen один раз на установку, сохраняется root-only, не заменяется при retry. Никаких чужих ресурсов adopt/delete.

Службы только собственные: firewall, Compose lifecycle, renew timer/service. Docker restart policy on-failure (не автоматическое восстановление до firewall при boot), own unit запускается послеfirewall, PartOf+WantedBy Docker обеспечивают восстановление после его рестарта без глобального fail-closed зависимости других проектов. ExistingDocker не обновляется. Localrollback не удаляетDocker и общие зависимости; remote records остаются скрытыми, пока владелец явно не удалит их.

DNS: определение authoritative NS, проверка A/AAAA, ручная запись при отсутствии предоставленногоAPI. Зарезервированные panel/sub/backup запрещены. DefaultTLS — собственный ACME HTTP01; BYO новыйcert/key также проверяются поhostname/chain/keypair. Публичная доступность и активныйVPN не подменяются фактомrunningcontainer: READY FOR TESTING; unknown checks явноUNKNOWN. Встроен optional doctor-test с предоставленной тестовой конфигурацией.

Распространение: отдельный public export только installer directory послеsecret scan; приватный исходный проект не раскрывается. Самодостаточный script, versioned releases, trustedSHA256 из отчёта как независимый trust anchor, безcurl|bash. Production first-live-test выполняет владелец позже.
